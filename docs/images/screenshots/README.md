# Screenshots

Put the app screenshots here, as PNG files with these exact names. The page shows each one that exists and hides the others.

| File | Screen | Used for |
| --- | --- | --- |
| `virtual-devices.png` | Virtual Devices, with a device running | The large image at the top of the page |
| `dashboard.png` | Dashboard | Gallery |
| `setup.png` | The guided setup | Gallery |
| `sdk-packages.png` | SDK Packages | Gallery |
| `activity.png` | Activity | Gallery |
| `settings.png` | Settings | Gallery |

How to take them:

- Open DroidDesk at its default window size (980 × 640 points).
- Use the light appearance.
- Press ⇧⌘4, then Space, then click the window. macOS saves the window with its shadow on a transparent background.
- Check that no user name or private folder name is visible. The paths show `~/…`, but look anyway.
- Keep the retina size (about 1960 × 1280 pixels). The page scales them down.
